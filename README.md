# HR Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition and workforce trends using Excel and Power BI to help understand employee retention patterns.

## Tools & Technologies
- **Excel:** Employee data cleaning and preparation
- **Power BI:** Data visualization and interactive dashboard development

## Analysis Performed
- Prepared employee data using Excel.
- Analyzed employee attrition patterns and workforce demographics.
- Visualized key HR metrics using Power BI.
- Developed a dashboard to present workforce trends and attrition insights.

## Key Metrics
- Employee Count
- Attrition Count
- Attrition Rate
- Average Employee Age
- Department-wise Attrition

## Conclusion
This project demonstrates the use of Excel and Power BI to analyze workforce data and communicate employee attrition insights through data visualization.
